## Dataset

This project uses the **WikiArt-10K dataset** for artistic style classification.

- **Dataset link:** [WikiArt-10K on Hugging Face](https://huggingface.co/datasets/tellow-it-1/wikiart-10k)
- **Task:** Art style classification
- **Image size:** 224 × 224 pixels
- **Classes:** 16 art styles in the processed dataset

The dataset and trained model weights are not included in this repository. Please refer to the dataset link and project scripts for data preparation and training instructions.
